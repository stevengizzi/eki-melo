Stage 3 — Harmonic plan (LLM)

Fourth LLM stage (Session 11) — the chords themselves. For the fully LLM (incl. harmony) case this calls generateHarmonicPlan (live model) and the generated harmonic plan flows into Stage 4 + 5a + 5b + Stage 6/8. For cases that supply a harmonicPlan it shows n/a. The prompt (built by buildHarmonicPlanPrompt) gives the model the available diatonic chords for the mode, the cadence/mode compatibility table, the memorable-progression exemplars, and explicit guidance on harmonic function + harmonic rhythm + B-section contrast; the raw response is parsed + validated (Roman-numeral validity, bar coverage, cadence/final-chord + mode compatibility), retried once on a validation error. Soft notes (all-tonic, static section, modal borrows) surface below, never a failure.
